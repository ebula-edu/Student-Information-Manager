# 📚 **Project Overview**

**Listah** is a modern, responsive, and beginner-friendly **Student Information Manager** developed as a requirement for **Computer Programming 1** at **Navotas Polytechnic College**.

The project focuses on simplicity, usability, clean UI/UX, and practical student data handling while maintaining a visually polished and engaging experience.

Built using core web technologies, **Listah** demonstrates how thoughtful interface design and functional programming logic can transform a simple academic project into something intuitive, smooth, and memorable.

> *Translation:*
> We turned “add student” into a cinematic experience.

---

# ✨ **Core Features**

## 📋 **Student Management**

* Add student records instantly
* Store **Name**, **Year**, and **Section**
* Delete entries in real time
* Dynamic student list updates
* Organized and readable data presentation

---

## 🎨 **UI/UX & Design Experience**

* Smooth list animations and transitions
* Animated empty-state feedback
* Clean modern interface
* Responsive on desktop, tablet, and mobile
* Balanced spacing, typography, and layout
* Intuitive button placement and forms
* User-friendly interactions focused on accessibility
* Carefully selected color palette for readability and aesthetics

> *We believe even school projects deserve good design.* ✨

---

## 💾 **Data Handling**

* Persistent local storage support
* Offline-friendly functionality
* Lightweight and optimized performance
* Structured and modular codebase
* Easy maintenance and scalability

> *No databases were harmed during development.*
